# Závazek

Příběhová hra o obyčejném klukovi ročníku 1970, který se v letech 1988–1989 rozhoduje, jestli spolupracovat s StB, a následky svých rozhodnutí potkává ještě po letech. Tón: Orwell × Švejk.

Hra má šest kapitol (1988–2026) a je dohratelná do konce. Celá hra je jediný soubor `index.html` bez build kroku, takže ji Vercel nasadí jako statickou stránku.

Všechny postavy a místa jsou smyšlené.
